# Сурма · Surma

Приватний застосунок повітряної тривоги для Android: без реклами, без трекінгу, без власного сервера.
Читає публічний канал Повітряних сил ЗСУ і показує загрози сповіщеннями та на карті.

> ⚠️ Сурма — додаткове джерело. Розпізнавання тексту може помилятися.
> Вона не замінює сирену, офіційні сповіщення та вказівки місцевої влади.

Код написано за допомогою ШІ (Claude, Anthropic) під керівництвом і з тестуванням автора.

---

Private air-raid alert app for Android: no ads, no tracking, no backend of its own.
It reads the public channel of the Ukrainian Air Force and shows threats as notifications and on a map.

> ⚠️ Surma is a supplementary source. Text recognition can be wrong.
> It does not replace sirens, official alerts or instructions from local authorities.

The code was written with AI (Claude, Anthropic), directed and tested by the author.
